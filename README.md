# Signal & Chance Lab

`Signal & Chance Lab` — учебное веб-приложение по теории вероятностей и основам статистики. Проект сделан как интерактивная лаборатория: студент может запускать эксперименты, решать задания, смотреть короткие теоретические блоки и отслеживать свой прогресс.

## Что есть в проекте

- лаборатории по монете, кубику, биномиальным опытам и нормальной выборке;
- теория по темам с интуицией, формулой и типичной ошибкой;
- практические задания с проверкой ответа и пояснением;
- дашборд с прогрессом, историей действий и рекомендациями;
- режим повторения слабых тем;
- CRUD-страницы для тем и заданий.

## Стек

- Python
- Django
- SQLite
- Django Templates
- CSS

## Запуск проекта

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_signal_lab
python manage.py runserver
```

После запуска проект будет доступен по адресу `http://127.0.0.1:8000/`.

## Основные страницы

- `/` — главная страница;
- `/labs/` — список лабораторий;
- `/exercises/` — список заданий;
- `/topics/<slug>/` — теория по теме;
- `/dashboard/` — дашборд прогресса;
- `/history/` — история учебной активности;
- `/review/` — режим повторения;
- `/content/` — управление темами и заданиями.
